# Screenshots

Place release screenshots in this folder. Filenames referenced from the root README:

| File | Description |
|------|-------------|
| `homepage.png` | Landing page (hero + features) |
| `login.png` | Login / register screen |
| `chat.png` | Chat welcome or conversation view |
| `workflow.png` | Agent run with status + result cards |

Capture tips:

1. Run `npm run dev` and open `http://localhost:3000`
2. Use a consistent viewport (e.g. 1440×900 desktop)
3. Export PNGs with the exact names above

Do not commit placeholder binary files; add real captures when ready.
